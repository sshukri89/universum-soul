# Universum Soul website

Complete static bilingual website for `https://universumsoul.nl/`.

## Languages

- Dutch is the primary language and is served from the website root.
- English is served from `/en/`.
- Every Dutch and English page has a self-referencing canonical URL and reciprocal `hreflang` links.

## Publish

Upload the contents of this folder to the document root of the domain. `index.html` must be directly in that root. Do not upload the parent folder as an extra nested directory.

For GitHub Pages, publish the repository root and keep the included `CNAME` file. For another host, upload all files and folders while preserving their relative paths.

## After publishing

1. Open the Dutch and English homepages.
2. Test the menu and language switcher on mobile and desktop.
3. Submit `https://universumsoul.nl/sitemap.xml` in Google Search Console.
4. Request indexing for the homepage and the main Dutch service pages.
5. Do not remove old indexed URLs. Use a permanent 301 redirect if a URL is ever replaced.
