# Universum Soul One Page Website

## Bekijken
Open `index.html` in een browser.

## Publiceren via GitHub Pages
1. Maak een openbare GitHub repository.
2. Upload de inhoud van deze map, niet het ZIP-bestand.
3. Ga naar Settings, Pages.
4. Kies Deploy from a branch, `main`, `/root`.
5. Open de link die GitHub toont.

## In Google Sites plaatsen
1. Publiceer deze pagina eerst via GitHub Pages of Netlify.
2. Open Google Sites.
3. Kies Invoegen, Insluiten, URL.
4. Plak de openbare URL en vergroot het frame.
